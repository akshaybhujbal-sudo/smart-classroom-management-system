Project Overview & Architecture Guide

Viva Defense Ready

Smart Classroom Management System

A complete, high-performance college engineering mini-project engineered using a Modern Python Flask backend and a responsive HTML5/CSS3/JavaScript single-page frontend. Designed for local intranet or laboratory demonstration without third-party cloud dependencies or runtime interpreters.

Python Backend Architecture

Built in Python utilizing Clean Architecture, RAII, and Object-Oriented Services (StudentManager, AttendanceManager, TimetableManager, ClassroomManager, ReportService).

Zero NPM Dependencies

Frontend is crafted using pure semantic HTML5, modern CSS variables, and native ES6 Fetch API. Starts instantly without Node.js or bundlers.

Atomic File Persistence

Data is saved via reader-writer mutex locks (std::shared_mutex) and atomic temp-file replace, preserving records across server restarts.

Hardware Extensibility (Future Scope)

The simulated environmental telemetry and appliance switches are decoupled behind clean service interfaces. In future development, physical microcontrollers (e.g., ESP32 or Arduino Uno with DHT11/DHT22 temperature sensors and relay modules) can be connected over serial UART or Wi-Fi without altering business logic or frontend views.

College Viva Talking Point: "Why Python for a web backend?" — Python provides rapid development velocity, clean readable syntax, extensive scientific & IoT libraries, and flexible REST API frameworks like Flask.
